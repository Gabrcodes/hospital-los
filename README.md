# 🏥 Hospital Length-of-Stay Prediction

**CSE271 - Data Science Methodology | Spring 2026 | Egypt University of Informatics**

## Project Overview

This project predicts hospital length of stay using the Microsoft Hospital LOS dataset.

- **Regression:** predicts exact LOS in days.
- **Classification:** predicts LOS risk class: Short (0-3d), Medium (4-7d), or Long (8+d).
- **Dashboard:** loads the trained models and saved metrics generated by `models.py`.

## Dataset

[Microsoft Hospital LOS Dataset](https://www.kaggle.com/datasets/aayushchou/hospital-length-of-stay-dataset-microsoft) - about 100,000 patient records.

Place `LengthOfStay.csv` in the project root before running the code.

## File Relationship

```text
LengthOfStay.csv
      ↓
models.py
      ↓
saved_models/ + plots/
      ↓
dashboard.py
      ↓
interactive predictions, metrics, and visualizations
```

`models.py` is the source of truth. It trains models, evaluates them, saves the best trained pipelines, writes metrics, writes feature importance, and generates plots.

`dashboard.py` does not hard-code model results. It loads the saved artifacts produced by `models.py`.

```bash
python -m venv .venv
.\.venv\Scripts\activate

```

## Run The Dashboard

```bash
streamlit run dashboard.py
```

Run `python models.py` before opening the dashboard. If saved models are missing, the dashboard will show a warning.

Classification models:

- Logistic Regression (MUST)
- K-Nearest Neighbors (MUST)
- Linear SVM (BONUS)
- Random Forest Classifier (BONUS)
- Neural Network / MLP (BONUS)

## Preprocessing

The model pipelines handle preprocessing safely:

- Leakage columns are removed: `eid`, `vdate`, `discharged`, `facid`.
- Numeric features are median-imputed and scaled.
- Categorical features are one-hot encoded.
- Preprocessing is fitted only on the training split inside each model pipeline.

## Key Results

Run `python models.py` to generate the latest results. The authoritative metrics are saved in:

```text
saved_models/metrics.json
```

The dashboard reads from this file so the dashboard and training pipeline stay consistent.
